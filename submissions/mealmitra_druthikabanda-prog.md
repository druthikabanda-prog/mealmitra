## Problem and solution

Surplus food generated by university dining halls, college canteens, bakeries, and local restaurants often goes to waste because staff lack the time to rapidly structure food details, formulate safety alerts, and coordinate urgent pickups before perishable deadlines expire.

**MealMitra** is an offline-capable Progressive Web App (PWA) with local AI designed for rapid surplus food organization and redistribution:

**Input → Output Workflow:**
1. **Input**: A kitchen donor enters basic surplus items (e.g., "15 portions of Vegetable Biryani", prep time, 4-hour pickup deadline, storage conditions, and allergen disclosures).
2. **Local AI Inference**: Google Gemma 4 runs 100% locally via Ollama on loopback without internet access. It formats the facts into a structured public listing, an emoji-formatted copyable sharing alert for WhatsApp/SMS, and deterministically highlights missing safety details in a checklist.
3. **Offline Resilience**: When internet access is unavailable in commercial kitchen basements, listings are saved locally to IndexedDB as "Saved Draft — Not Published". Once reconnected, users safely synchronize drafts to SQLite with one click.
4. **Recipient Claims**: Nearby student pantries and food shelters review active surplus listings and submit claim requests with real-time server duplicate prevention.

## Approach and technologies

- **Frontend**: React 18, Vite, Tailwind CSS, Lucide React icons.
- **PWA Architecture**: Progressive Web App with Web App Manifest (`manifest.json`), custom app icons, and Service Worker (`sw.js`) implementing Stale-While-Revalidate caching for app shell and assets.
- **Client Storage**: IndexedDB (`MealMitraDB`) storing cached listings and offline listing drafts with status flags.
- **Backend**: Python Flask REST API with SQLite database in WAL mode (`PRAGMA journal_mode = WAL`) and 30-second busy timeout for concurrent safety.
- **Local AI Model**: Google Gemma 4 (`gemma4:e2b` / `gemma:2b`) running locally via Ollama at `http://localhost:11434`. Runs completely offline without internet or cloud APIs.

### Best Use of Gemma 4

- **Local Ollama Integration**: Flask connects directly to Ollama's Chat API (`POST /api/chat`) using structured JSON output mode (`format: "json"`).
- **Responsible AI Guardrails**:
  - **Zero Algorithmic Certification**: Gemma explicitly never certifies that food is biologically safe to eat or fresh.
  - **Zero Hallucination**: AI never invents missing expiry dates, quantities, storage history, or allergens.
  - **Safety Checklist**: Any unspecified parameter (e.g., undeclared allergens or unrecorded prep times) is automatically flagged in `missing_details_checklist`.
  - **Zero-Mock Policy**: If Ollama or the local model is offline, the system returns clear error details rather than misleading mock data.
